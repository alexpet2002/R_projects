# R_projects
repository of projects in R for data science.

**[Hierarchical and Kmedoids Clustering for Hotel Reservation Behaviour](https://github.com/alexpet2002/R_projects/blob/main/notebooks/clustering/Clustering.md)**

**Description:** Clustering analysis of hotel reservations using Hierarchical Clustering and K-Medoids (PAM). The project compares both approaches on mixed-type booking data to identify meaningful reservation groups and examine how booking characteristics relate to cancellation behavior.
